# Fitted settings used in the current results

The GEFCom parameter table contains 990,000 state-price rows (10 held-out zones,
3 seeds, 5 prices, 6,600 complete states); the commercial table contains 198,000
rows (2 anonymous farms, 3 seeds, 5 prices, 6,600 states). These are fitted choices,
not a fresh search. Join each table to its accompanying state definitions.
The support level records the initial fit; it can change during local sequential
updates. Counts, shrinkage parameters, beta and prescribed tolerances stay fixed
during testing. Frequency tables count states, not forecast cases.

Baseline configurations and exact source hashes are retained. The archived
commercial protocol's historical status describes when choices were frozen;
it is not an indication that the reported experiments are incomplete.
These configuration tables contain no raw SCADA/NWP, calendar-to-tick mapping,
physical capacity or site identity.
