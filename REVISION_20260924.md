- A no-backoff ablation that estimates from sparse nonempty exact states and
  retains empty-history forecasts with a Static fallback.
- Current Tables 5–7 and supplementary tables S1–S10.

  programs for result figures, and supporting numerical inputs.

are explicitly marked historical; their original tree is preserved in Git.

remain applicable. The code repository stays private and the release stays a
draft. This update does not publish the manuscript or release raw farm data.

condition-summary checks and full experiment replay. Rebuilding every model or
ablation is not claimed by the portable summary checks. Detailed checks live in
the relevant result and validation directories.
